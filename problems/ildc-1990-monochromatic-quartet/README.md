# ILDC 1990 单色四片式

赛题规定四片 BK7 球面折射镜，氦 d 线 587.56 nm，无限远物体，EFL 100 mm、F/3、半视场 15°，使用同一平像面。玻璃最小厚度为 2 mm，畸变小于 1%，并要求全视场无渐晕。评分取三个视场的几何 RMS 点斑半径的算术平均。原题允许自选光阑位置，镜头尺寸无规定上限。 [原赛题结果论文](https://doi.org/10.1117/12.47896) · [题面转录及公开参考处方](https://www.genetic-programming.org/hc2007/06-Gagne/Gagne-RT-LVSN-2007-01.pdf)

## Optiwork v1.2 复验

采用 Optiwork 玻璃目录的 SCHOTT N-BK7，同波长折射率为 1.51680011，符合赛题给定精度。处方以论文图 5 的 Williamson #14 为起点，重做了轴向分配、曲率和外径。光线追迹、光学优化、制造几何及公差采样均使用 Optiwork v1.2。撤除了早期练习自设的中心厚度和总长上限。

| 项目 | 复验结果 |
| --- | --- |
| EFL | 100.000248 mm |
| F 数 | 3.0000074 |
| 三场几何 RMS 点斑半径 | 0° 为 2.8780 µm，10.5° 为 1.0926 µm，15° 为 2.7771 µm |
| 三场平均 | **2.249226 µm**，达到 2.25 µm 练习目标 |
| 最大质心畸变 / 主光线畸变 | 0.2689% / 0.2694% |
| 通光 | 0–15° 共 31 个视场，采样的全部瞳孔内部和边界光线通光 |
| 光学总长 / 后焦 | 356.066 mm / 1.911 mm |

最大质心畸变采用赛题口径，另列主光线结果便于核对。三个评分视场采用 32 个径向节点和 128 个方位。全视场通光复验每场取 20 × 64 个内部节点，并加入 128 条精确边界光线。

## 制造几何初审

按实体全口径检查最薄处、曲面间距和分级环形支承空间。相邻实体最小轴向净距 0.600 mm，末面与像面最小轴向净距 1.598 mm。末面用三场几何审计求得的最小径向通光余量约 0.050 mm。

Optiwork 名义几何检查通过。单项厚度和空气隙公差探测共有 14 个端点，其中 9 个端点获得处方通光并完成测量，补偿后的有效端点中最大平均点斑为 2.519 µm。剩余端点未能找到有效的共用调焦补偿。批量良率、独立定心与两块长毛坯的供货和加工仍待确认。 [SCHOTT 光学玻璃资料](https://www.schott.com/en-us/products/optical-glass) · [SCHOTT 球面加工能力](https://media.schott.com/api/public/content/4458fe0487604d478e7f924c572364d2?download=true&v=5fc613d7)
