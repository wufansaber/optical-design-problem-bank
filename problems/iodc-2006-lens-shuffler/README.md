# IODC 2006 Lens Shuffler

将一根 100 mm 长的 SCHOTT N-BK7 玻璃柱沿轴向的内部曲面交替取片，保留所有原始间隔，形成 A、B 两套镜头。重叠原轴向坐标时，A 的空气间隔由 B 的镜片填入，B 的空气间隔由 A 的镜片填入。两套须具备相同焦距、入瞳和视场，并达到近衍射极限的像质。评分为公共入瞳直径乘半视场。 [大会档案](https://iodc.info/iodc-2006/) · [结果论文](https://doi.org/10.1117/12.695230) · [公开摘要](https://www.researchgate.net/publication/271465523_2006_IODC_lens_design_problem_the_lens_shuffler)

## Optiwork 设计与 Zemax 对照

在 Optiwork v1.2 根据共享的分片表生成 A、B 两套处方，比较不同分片几何及共同的入瞳和视场。两套设计保留玻璃片在同一根首尾为平面、总长 100 mm 的圆柱内的轴向位置。本次统一取 587.56 nm、100 mm EFL，在固定像面分别核对保留倾斜与去除倾斜的 RMS，两种算法均以 0.070 波作检查线。完整报名题面中的波前定义仍待原件复核。将两份冻结处方分别转换为 Zemax 原生文件，重新打开后回读面数据并独立追迹实光线。
