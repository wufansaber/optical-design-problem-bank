# IODC 2023 Yin-Yang Lens

只用 SCHOTT N-BK7 和 N-SF6 球面或平面折射镜。550 nm 焦距为 100 ± 0.1 mm，全场 RMS 波前须 ≤ 0.070 波。540 与 550 nm 的近轴像距差须 ≤ 0.0001 mm，并在同一固定像面评价。评分为 550 nm 入瞳直径 × 半视场 × 540 nm 轴上 RMS 波前。全长 ≤ 500 mm，各片空气分隔，光路须避免全反射、遮挡和中间实像。 [原题](https://iodc.info/2022/08/the-2023-iodc-shafer-cup-competition/) · [官方 FAQ](https://iodc.info/2022/08/the-2023-iodc-shafer-cup-competition-faq/)

## Optiwork 设计与 Zemax 复验

先根据 Optiwork 的两波长折射率，用两个曲率变量约束 550 nm 焦距与两波长近轴像距差。筛选有空气隙的双片、三片和四片，再用 Optiwork v1.2 的原生波前计算调整弯曲、间隔和公共像面。冻结入选的 3 片处方和实体光阑，Zemax 重建、保存并重开同一处方，逐面核对半径、间距、玻璃、清口径和实体直径。

| 验收项 | Optiwork v1.2 | Zemax OpticStudio 2022 R2.02 |
| --- | ---: | ---: |
| 550 nm 焦距（mm） | 100.000000 | 100.000000 |
| 550 nm 真实入瞳（mm） | 6.600000 | 6.600000 |
| 半视场（°） | 4.450000 | 4.450000 |
| 两波长近轴像距差（mm） | 0 | 1.14e-13 |
| 550 nm 最大 RMS，51 × 51 网格（波） | 0.06367241 | 0.06367241 |
| 540 nm 轴上 RMS，51 × 51 网格（波） | 0.06486917 | 0.06486917 |
| 相同采样得分（mm·°·波） | 1.90520748 | 1.90520748 |

按 FAQ 的 25 个均匀视场，Zemax 另算 **50 × 50** 矩形瞳孔网格，得到 550 nm 最大 RMS **0.06351975 波**、540 nm 轴上 RMS **0.06471354 波**，相应复算得分 **1.90063658 mm·°·波**。两套软件的相同网格 550 nm 逐场最大差为 2.3e-10 波。Optiwork 的矩形网格需要奇数边长，故用 51 × 51 作同采样对照。两种网格均以固定像面去活塞和倾斜、保留离焦。 [官方 FAQ](https://iodc.info/2022/08/the-2023-iodc-shafer-cup-competition-faq/)

在 51 × 51 网格上，Optiwork 的 550 nm 轴上 RMS 为 0.06367241 波。Zemax 在 50 × 50 网格上的对应值为 0.06351975 波。结果为已复验的基础解，历史比赛统一使用 CODE V 评分。 [结果论文](https://opg.optica.org/abstract.cfm?uri=IODC-2023-1279837)

## 实体光阑与名义几何

实体光阑由 550 nm 轴上真实边缘光线定径。两波长在 49 个场点的瞳内与瞳缘采样全部通光，轴上实际光线与近轴检查均未出现光学列内的中间轴交点。总长 111.172 mm，最大成品外径 15.236 mm，最小边厚 4.395 mm，最小玻璃净距 3.327 mm。名义实体检查通过，工装、材料实物和装配公差仍待验证。
