# Optiland 24 mm F/4 广角

赛题要求全视场 60°，EFL 24 mm ±2%，F/4 ±5%，5–8 片球面或平面折射镜，后焦至少 12 mm，总长不超过 80 mm，且所有验证场角的 d 线绝对畸变不超过 2%。在四个评分场，按 20 lp/mm 子午和弧矢多色衍射 MTF 相对 1 的均方偏差评分。三色共用一个固定平像面。 [裁判规则 2.1.0](https://github.com/optiland/challenges-eval/blob/main/RULES.md)

以公开反远摄样例为起点，在 Optiwork v1.2 调整曲率、轴向间隔和固定像面。完成光阑和清口径冻结后，将同一处方转入 Zemax，重读曲率、厚度、玻璃和光阑，并逐片核对三色折射率。处方按物方向列出的玻璃为 SCHOTT:N-SK16、SCHOTT:N-SK16、SCHOTT:N-BASF2、SCHOTT:N-FK5、SCHOTT:N-SF15、SCHOTT:N-LAK12。 [公开反远摄起点](https://github.com/optiland/challenges-eval/blob/9276cf30d26a7f38df0ac9a89e07c323e60e23fa/examples/wide_angle.json)

两套软件均使用等权 486.1327、587.5618、656.2725 nm。在 0–30° 每个整数场角复验主光线、256 条边缘光线及两档面积采样，93 个场角与波长组合均全瞳通光。

Optiwork 采用 512 瞳孔采样评分，按评分场顺序用 256 / 256 / 256 / 1024 对照。Optiwork 的 256 档在 30° 触发相位欠采样提示，因此该场采用更密的两档复验。Zemax 使用 256 / 512 瞳孔采样。20 lp/mm 的最大格点收敛差依次为 0.00035、0.00048，跨软件最大 MTF 绝对差为 0.00127。两套软件各自采用原生衍射实现，表中给出本地评分。

用同处方运行公开裁判程序，按题面规定的 256 / 512 瞳孔与 1024 / 2048 FFT 网格判定为 `eligible`。本机评分为 **0.585833**，同环境复算的公开样例为 0.703310，分数越低越好。裁判报告记录了本机环境与官方锁定版本的差异。 [公开裁判程序](https://github.com/optiland/challenges-eval/tree/9276cf30d26a7f38df0ac9a89e07c323e60e23fa)

## 名义制造几何

最大成品外径 29.402 mm，最小中心厚度 2.200 mm，最小边厚 1.291 mm，相邻实体最小轴向净距 1.914 mm，最大实体边缘斜率 2.226。Optiwork 的成品半径域几何检查通过。玻璃供货、陡面加工与检测、装配和实物公差仍需确认。
