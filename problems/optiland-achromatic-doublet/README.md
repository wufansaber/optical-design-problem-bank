# Optiland 消色差双片

赛题要求无限远物体、两片球面折射镜和三条等权谱线。d 线 EFL 为 100 mm ±1%，入瞳直径为 12.5 mm，后焦距离至少 60 mm。半视场 0–3° 内，最大绝对畸变为 0.5%，F–C 近轴后焦位置差不超过 0.10 mm，且全瞳通光。正镜片使用较大阿贝数的玻璃。评分用 0°、1.5°、3° 的共质心多色 RMS 点斑，分数越低越好。 [裁判规则 2.1.0](https://github.com/optiland/challenges-eval/blob/main/RULES.md)

## 处方

用 Optiwork v1.2 对目录玻璃、胶合与空气分隔两种结构做实光线搜索。入选方案为 SCHOTT N-FK51A／N-KZFS4 胶合双片。光阑设在第一折射面，共用一个固定平像面。轮廓按照实际机械外径逐片审核，赛题的最低中心厚度与最低边厚分别为 2 mm 和 1 mm。

## 制造几何

名义机械外径 16.80 mm，最小中心厚度 4.855 mm，最小机械边厚 3.336 mm。Optiwork 完整口径实体几何检查通过。名义 EFL 距赛题上限还有 0.0100 mm，实物焦距是否能守住上限仍需公差验证。本次未建立实际装配、采购或统计良率证明。
