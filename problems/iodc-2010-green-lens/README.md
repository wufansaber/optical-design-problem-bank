# IODC 2010 Green Lens

只使用 SCHOTT N-BK7 和 532 nm 单色光。系统为无限远物、空气中的平直实像，球面共用一个半径绝对值，也允许平面。焦距绝对值必须在 100.00 ± 0.01 mm 内，所有玻璃和空气间隔保持正厚度，评分视场内全瞳通光。RMS 波前以主光线为参考，保留倾斜和离焦，须不超过 0.070 波，绝对畸变须不超过 5%。评分为入瞳直径乘半视场，分数越高越好。 [大会档案](https://iodc.info/iodc-2010/) · [完整题面存档](https://es.scribd.com/document/36298694/The-Green-Lens)

## 设计与双软件验收

在 Optiwork v1.2 比较三片到六片的全折射结构。每个候选锁定各球面半径的绝对值，筛选不同的正负曲率排列、厚度和空气间隔，再联合搜索入瞳、半视场和一个固定像面。入选的 3 片结构为正焦距合题基础解。冻结实体光阑后，在原生 Optiwork 处方上复核，再由 Zemax 重读同一处方并复算。

两套软件复验了从轴上到申报边场的 43 个场点，使用同一个实体光阑和固定像面。Optiwork 用 16 × 64 和 32 × 128 瞳孔面积积分，并追迹含精确瞳孔边缘的样本。Zemax 使用 28 × 96 瞳孔积分以及 256 条近瞳缘光线，直接读取对主光线的 OPD，再计算其 RMS。全部采样通过，跨软件波前最大差 3e-10 波。此处得分按双软件已复验的视场计算。

## 名义几何

最大成品外径 31.411 mm，最小中心厚度 2.088 mm，最小边厚 0.722 mm，最小相邻玻璃轴向净距 6.067 mm，光阑平面两侧的最小净距 8.122 mm。实体几何检查通过，材料实物、装配和公差仍需验证。该方案的孔径和得分与历史优胜设计有显著差距。 [竞赛结果论文](https://doi.org/10.1117/12.871174)
