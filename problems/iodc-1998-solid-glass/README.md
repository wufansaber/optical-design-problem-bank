# IODC 1998 实心胶合镜头

采用直通折射类别。题面要求无限远成像、F/1.8、50 mm 圆形平面探测器、球面目录玻璃，第一片到最后一片之间全胶合。按光学清口径算出的玻璃质量须小于 1 kg，满场相对照度须超过 70%。评分采用 0、0.7、0.8、1 倍实际像高的几何多色 RMS 点斑半径，权重为 1、1、1、0.5。F、d、C 三条谱线取 486.1、587.6、656.3 nm 等权。 [大会原始题面](https://iodc.info/1998/06/1998-lens-design-problem/)

## Optiwork 设计与 Zemax 复验

本题解为七片胶合的基础解，物方到像方材料为 SCHOTT N-FK58、N-LASF44、N-FK58、N-SF57、N-FK58、N-PSK53A、N-LAK12。在 Optiwork v1.2 比较三片、五片和七片起点，用总质量约束优化球面曲率和轴向尺寸，再冻结实体光阑、清口径和共用像面。七片起点的加权点斑为 4404.82 µm，入选版为 874.94 µm。Zemax 通过保存重读逐面核对处方和三条谱线的折射率。

## 实体与像质边界

成品外径 61.484 mm，最小中心厚度 8.894 mm、最小边厚 0.630 mm、两面最小实体距离 0.630 mm。按成品外径计玻璃质量约 984.45 g。胶层、镜筒和公差需实物验证。

像质仍远低于当年高分处方。Seppala 公开的表 1 处方在关闭瞳孔瞄准的 Optiwork 诊断中为 18.28 µm，包含 0.001 mm 的中心厚度。该诊断保留旧玻璃和边场遮拦，作为历史像质参照。 [Seppala 公开处方](https://www.osti.gov/servlets/purl/2804)
