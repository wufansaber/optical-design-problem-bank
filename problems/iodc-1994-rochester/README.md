# IODC 1994 Rochester · Camera in a Can

在 632.8 nm 用 SCHOTT 玻璃和球面折射镜，对无穷远物在平面上成像。公开的赛题说明要求全瞳通光和最大 RMS 波前误差 0.070 波，由约 4 mm 的近轴像方 NA 与半像高乘积表示一亿个艾里斑的分辨能力。评分按包住全部镜片和有效像面的最小同轴圆柱体积。 [会议论文目录](https://opg.optica.org/conference.cfm?meetingid=22&yr=1994) · [历史题目说明及处方](https://groups.google.com/g/sci.optics/c/hIpcOLaUKAU)

## Optiwork 与 Zemax 对照

从 Dan Reiley 公开的历史处方出发，在 Optiwork v1.2 恢复近轴像面求解和处方的离焦量，用实光线重建未使用场点渐晕因子的镜片通光口径。输出 10 片的球面与直线锥边几何。两套软件分别重开冻结后的原生处方，核对折射率、面数据和 41 个场点的波前。波前比较移除活塞和倾斜，保持固定像面。

所有采样场点均在瞳内和瞳缘通光，最大逐场 RMS 差为 1.5e-10 波。体积复算结果为 **14.435 cm³**，圆柱长 45.4188 mm、直径 20.1162 mm。像面半径取边场实光线主光线像高 10.0581 mm，成品半径和各面矢高均纳入包络计算。

## 名义几何

检查球面及直线锥边轮廓在共同径向范围内的实体间隙，并核对实光线段在锥边界内。球面共同半径内的最薄厚度为 1.0000 mm，镜片之间最小名义间隙为 21.63 µm，轴上后像距为 1.00 µm。历史方案的实体结论针对记录中的锥边尺寸，倒角、装调、公差和探测器封装仍待验证。
