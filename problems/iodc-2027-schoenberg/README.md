# IODC 2027 Schoenberg Lens

两个球面折射镜片的基础解。赛题要求每片镜的前后半径、中心厚度和后续空气间隔恰好用完 0–9，每个数字只用一次。系统使用 587.6 nm、折射率 1.49032，焦距 98.7 ± 0.1 mm，总长不超过 523.46 mm。光阑在两片镜之间的平面上，全视场 RMS 波前误差不超过 0.0701 波，绝对畸变不超过 9.865432%。波前计算移除活塞和倾斜，保留离焦。 [官方题面](https://iodc.info/2026/09/the-2027-iodc-shafer-cup-competition/) · [官方 FAQ](https://iodc.info/2026/09/the-2027-iodc-shafer-cup-competition-faq/)

## 文件和复现

先将 [SCHOENBERG.agf](SCHOENBERG.agf) 导入 Optiwork 材料库，并放入 Zemax 的 `Glasscat` 目录，然后打开 [Optiwork 处方](lens.owx) 或 [Zemax 处方](lens.zmx)。该单色折射率模型来自题面。镜片边厚、空气间隔和光阑净距通过名义几何检查，实物玻璃选型、装调与公差仍待验证。
